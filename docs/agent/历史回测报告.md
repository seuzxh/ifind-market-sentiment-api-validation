# rules-v1 历史回测与回撤优化

回测日期：2026-09-09  
规则版本：`rules-v1`  
数据来源：iFinD `history_data` 18 条正式指数，2025-01-02 至 2026-09-08 的脱敏响应。原始响应只保存在本地 `data/backtest_evidence/`，不进入仓库。

## 方法

每个交易日收盘后计算主基准当日收益、Ret5、Ret20，以及 SIZE/RISK/MOM Spread；用下一交易日收盘相对当日收盘的收益检验方向。前 20 个交易日作为趋势预热，不产生信号。2026-05-25 及跨越该日期的样本全部剔除，A 段截至 2026-05-22，B 段从 2026-05-26 开始。

回测只用于判断规则是否有方向信息，不考虑手续费、滑点、涨跌停成交限制和仓位大小，因此收益不能直接当作可交易收益。

## 判断准确性

共得到 386 个有效的下一交易日观察：

| 信号 | 样本数 | 下一日方向命中率 | 下一日平均收益 | 最差下一日收益 |
|---|---:|---:|---:|---:|
| 偏强 | 127 | 56.69% | +0.1385% | -2.3724% |
| 偏弱 | 48 | 31.25% | +0.0541% | -12.1243% |

“偏强”有一定方向信息，但优势有限；“偏弱”在这段样本里反而经常错，不能直接转换成做空。

## 暴露策略对比

以下收益是每日满仓或空仓的简化结果，用于比较规则门禁，不代表实际组合收益。

| 策略 | 全样本收益 | 全样本最大回撤 | A段收益 / 回撤 | B段收益 / 回撤 |
|---|---:|---:|---:|---:|
| 全程持有参考 | +37.45% | -21.05% | +46.71% / -17.12% | -6.31% / -18.42% |
| 当前规则：偏强做多、偏弱空仓 | +18.56% | -4.24% | +15.17% / -4.24% | +2.95% / -1.49% |
| 当前规则：偏强做多、偏弱做空 | +13.94% | -11.79% | +14.30% / -11.79% | -0.31% / -9.99% |
| **保守规则：偏强且非 Risk-Off 才做多** | **+12.94%** | **-3.67%** | **+10.63% / -3.39%** | **+2.08% / -1.06%** |

在未调参数的 B 段外样本中，保守规则把最大回撤从 -1.49% 降到 -1.06%，收益从 +2.95% 降到 +2.08%。全样本最大回撤从 -4.24% 降到 -3.67%。这符合“优先避免大幅回撤”的目标，但代价是减少参与次数和收益。

## 已采用的优化

终端 Agent 现在额外输出 `drawdown_control`：

- `谨慎偏多`：方向为“偏强”，且风险模式为 `Risk-On` 或“中性”；
- `观望`：方向为“震荡 / 偏弱 / 证据不足”，或方向虽偏强但风险模式为 `Risk-Off`。

该字段是历史验证后的风险门禁，不是自动交易指令。`偏弱`仍然保留在市场判断中，但不会触发做空。

## 结论和限制

当前规则可以作为低频状态筛选，但不能宣称具备稳定预测能力。样本虽然扩展到约 18 个月，却仍只有两个分段，且没有交易成本、滑点和实际成交约束。`p00112` 纯 A 沪深京口径尚未完成供应商确认，所以本次方向回测没有把广度作为强制条件。

下一次验证应使用新增历史数据做滚动外样本复核；只有当保守规则在新增样本中仍能把最大回撤控制在预设上限内，才考虑调整阈值或增加信号。SQLite 和 Web/API 继续暂缓。
