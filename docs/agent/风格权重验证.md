# SIZE、RISK、MOM 权重验证

日期：2026-09-11；实验版本：`weights-v1`。目标为同花顺全A `883957.TI` 下一交易日涨跌。方向判断仍只使用主基准当日收益、Ret5、Ret20；本实验只改变风险门禁的加权投票。

## 固定规则

每组 Spread 为正或为负时，分别累积其权重；正向或负向累计达到固定阈值2分，对应 `Risk-On` 或 `Risk-Off`，否则为“中性”。方向为偏强且非 `Risk-Off` 时，才产生“谨慎偏多”信号。

| 方案 | SIZE | RISK | MOM |
|---|---:|---:|---:|
| 等权基准 | 1.0 | 1.0 | 1.0 |
| SIZE优先 | 1.5 | 1.0 | 0.5 |
| RISK优先 | 0.5 | 1.5 | 1.0 |
| MOM优先 | 0.5 | 1.0 | 1.5 |
| RISK/MOM共识 | 0.5 | 1.0 | 1.0 |

上述方案在运行前固定，阈值始终为2分，没有网格搜索，也没有根据留出期结果回调权重。

## A段留出期结果

A段留出从2025-12-25开始，共94个观察。回撤和收益均按该段独立计算。

| 方案 | 谨慎偏多信号数 | 次日上涨命中率 | 收益 | 最大回撤 |
|---|---:|---:|---:|---:|
| 等权基准 | 19 | 57.89% | +5.54% | -2.64% |
| SIZE优先 | 25 | 56.00% | +6.61% | -4.24% |
| RISK优先 | 19 | 57.89% | +5.54% | -2.64% |
| MOM优先 | 21 | 57.14% | +5.87% | -2.64% |
| RISK/MOM共识 | 21 | 57.14% | +5.87% | -2.64% |

SIZE优先以更高回撤换取较多暴露，和“优先控制回撤”的目标不符。RISK优先没有改变实际谨慎偏多日期；MOM优先和RISK/MOM共识增加两次参与，命中率略降，回撤未改善。等权基准是本轮最合适的保留方案。

## B段与限制

B段只有54个有效观察，按既定前40项预热和70%切分，开发期没有可评估的谨慎偏多样本；留出期只有3至5次信号，不能用来选择权重。所有权重保持研究状态，`deployment_allowed=false`。

本轮数据此前已用于规则探索，时间留出不是全新盲测。收益和最大回撤为简化指数暴露，不含手续费、滑点和成交约束。权重影响的是风险过滤，不能把本报告的命中率解释成实时上涨概率。

机器结果见[weights-v1-results.json](weights-v1-results.json)，其中保存了输入响应SHA-256、开发期和留出期的完整统计。复现：

```powershell
$response = Get-ChildItem data/backtest_evidence -Recurse -Filter response.json | Select-Object -First 1
python weight_market_agent.py --response $response.FullName --output data/weights-results.json
python -m unittest discover -s tests -q
```
