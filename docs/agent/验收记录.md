广度补测：409日`p00112`、交易日历和主基准完整对齐；返回字段明确沪深两市，且全部等于沪市加深市，没有体现北交所。上涨占比超过50%的确认规则未改善留出表现，不提高默认广度权重。详见[广度确认实验](广度确认实验.md)。

广度扩展：固定检验7种改善、极端和背离形态，共14个视角。A段开发期选中的“单日改善”留出命中率48.94%，低于同日基准53.19%；其他高命中结果为小样本或前后期反转，均不接入默认规则。详见[广度扩展探索](广度扩展探索.md)。
