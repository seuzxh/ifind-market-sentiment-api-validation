# 次日上涨概率：第一轮验证

日期：2026-09-09；实验版本：`probability-v1`。目标是预测主基准下一交易日是否上涨，收益严格大于0为上涨，平盘为非上涨。短期暂缓手续费、滑点和成交约束，保留分段及风险检查。

## 本轮结论

尚未发现比简单基准更可靠的概率规则，暂不替换终端Agent默认判断。不能把历史“偏强命中率56.69%”直接当成今天的上涨概率。

同时修复了旧回测的跨段趋势窗口和净值串接，旧全样本回撤数字已撤下，见[纠正版回测](历史回测报告.md)。

## 固定实验设计

仅复用本地18条指数响应，没有新增接口调用或依赖。原始响应SHA-256保存在[实验结果](probability-v1-results.json)，原始行情和令牌不发布。

每段单独训练，先有20个交易日趋势预热，再累积40条已揭晓次日结果的训练样本。预测时只允许标签日期不晚于当日收盘的样本；不允许跨段训练、随机打乱或使用未来标签。

预先固定四种方法：

1. `base_rate`：该段过去上涨频率，做加一平滑。
2. `direction`：按原规则偏强、震荡、偏弱分组。
3. `risk_mode`：按Risk-On、中性、Risk-Off分组。
4. `daily_sign`：按当日上涨、下跌、平盘分组。

分组概率为 `(组内上涨次数 + 10 × 基准概率) / (组内样本数 + 10)`，小样本向整体频率收缩。未搜索阈值或平滑参数。

每段前70%用于开发，后30%按时间留出；若40条预热超过分割点，则顺延留出起点。开发期至少20条有效预测才选择候选，以Brier最小为准。进入留出期后方法固定，频率可逐日吸收已揭晓结果。全部候选均列出用于审计，不能再按留出成绩重选。

筛选要求：留出至少30条，Brier低于历史频率基准，准确率同时高于频率基准和始终预测上涨。筛选通过不等于统计显著，仍需新增数据复核，不能自动上线。

## 留出期结果

| 周期 / 方法 | 预测数 | 准确率 | Brier（越低越好） | 概率≥60%的次数 / 实际上涨率 |
|---|---:|---:|---:|---:|
| A：历史频率基准 | 94 | 53.19% | 0.25412 | 25 / 48.00% |
| A：开发期选中的direction | 94 | 53.19% | 0.25494 | 19 / 52.63% |
| A：risk_mode（仅审计） | 94 | 53.19% | 0.25484 | 43 / 46.51% |
| A：daily_sign（仅审计） | 94 | 53.19% | 0.25759 | 44 / 52.27% |
| B：基准（样本不足，不选模型） | 14 | 64.29% | 0.24521 | 0 / 不适用 |

A留出从2025-12-25开始；B留出从2026-08-19开始。A始终预测上涨也为53.19%；候选没有提升。A候选高概率覆盖率20.21%，其中最差次日收益-5.15%，说明“≥60%”也未得到可靠支持。B的64.29%只有14次，不能据此宣称提升。

输出同时记录概率分桶、覆盖率、最差收益和分段暴露回撤。Brier是概率误差综合指标，并不单独代表校准质量；分桶均值与实际上涨率一起查看。方法参考[时间顺序验证](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)和[概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)，实现使用Python标准库，不依赖scikit-learn。

## 适用限制与下一步

这份历史数据之前已被观察和用于规则探索，所以本次留出不是全新的盲测。使用的也是当前历史快照，未验证历史修订；标签来自相邻已返回交易日，尚未逐日对照交易日历排查供应商漏行。当前不输出经过验证的实时概率。

下一次只扩大同段历史覆盖，并先确定少量增量特征，如波动率、连续涨跌天数和成交额变化。仍按时间向前验证，并保留简单频率基准；新增规则要在未参与挑选的数据上胜出。B段不得借用跳变前的数据凑训练样本。当前B段仅54条有效观察，验证样本不足是实际限制。

SQLite、Web/API继续保留在原方案记录中，本轮不扩建。

## 复现

```powershell
$response = Get-ChildItem data/backtest_evidence -Recurse -Filter response.json | Select-Object -First 1
python probability_market_agent.py --response $response.FullName --output data/probability-results.json
python -m unittest discover -s tests -q
```

命令只读取本地响应，输出研究性验证结果，不读取令牌、不进行交易。输入同一响应应得到相同结果。
