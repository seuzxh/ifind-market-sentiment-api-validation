# 广度型亏钱效应验证

## 结论

当前框架已经能单独描述“多数股票正在亏钱”的广度型亏钱效应，但它不等同于个股亏损幅度。

A段（312个观察）中，`down_ratio >= 60%`共105次，次日同花顺全A上涨率64.76%，高于全样本58.65%；平均次日收益为+0.1914%。这更像极端扩散下跌后的短期反弹，不能直接解释为次日继续下跌。真正较差的是“偏强亏钱效应”区间：`50% < down_ratio < 60%`共42次，次日上涨率50.00%，平均收益-0.2767%，最差-12.1244%。

“指数上涨但下跌家数占优”在A段有19次，次日上涨率47.37%，平均收益-0.0324%，说明权重托举确实带有弱化提示，但样本仍不大。连续3日下跌占优在A段反而出现70.00%的次日上涨率和+0.4447%的平均收益，呈现均值回归特征，不能把连续下跌家数简单转成看空信号。

亏钱效应目前只作为线上快照的独立解释字段，不改变`rules-v1`方向判断，也不生成交易信号。

## 固定定义

数据来自`data_pool/p00112`，范围按已确认口径使用沪深纯A股，不要求北交所。

| 状态 | 固定定义 |
|---|---|
| 下跌比例 | 下跌家数 /（上涨家数 + 平盘家数 + 下跌家数） |
| 净广度 |（上涨家数 - 下跌家数）/ 总家数 |
| 强 | `down_ratio >= 0.60` |
| 偏强 | `0.50 < down_ratio < 0.60` |
| 不明显 | `down_ratio <= 0.50` |
| 连续2日下跌占优 | 截至信号日连续2个实际交易日`down_ratio > 0.50` |
| 连续3日下跌占优 | 截至信号日连续3个实际交易日`down_ratio > 0.50` |
| 指数上涨但下跌占优 | 当日`883957.TI`收益大于0，同时`down_ratio > 0.50` |

这些阈值在看结果前固定，不做网格搜索，也不按回测结果改阈值。

## 边界、时点与解释限制

- 2026-05-25排除。A段截至2026-05-22，B段从2026-05-26开始。20日行情窗口、预测日和连续广度窗口必须位于同一段。
- 信号只使用当日及之前数据，结果比较的是下一交易日`883957.TI`日收益，不使用未来广度。
- 原始409日广度中排除2026-05-25，保留408日；行情样本重新预热后为A段312条、B段54条。
- 只有涨跌家数无法衡量单只股票跌幅、跌幅分布、持仓成本和实际账户损失。因此当前是“广度型亏钱效应”，不是完整的个股赚钱/亏钱效应。
- 历史接口响应不能证明当时发布时间和后续修订状态，不是严格时点数据库。
- “状态序列段内最大回撤”是假设仅在该状态出现后的下一日持有基准所得的解释性序列，不是已部署策略。
