# 市场状态规则说明

当前规则版本：`rules-v1`

## 适用范围

首期只分析日频行情、风格 Spread 和市场广度。主基准是 `883957.TI`（同花顺全A，沪深京），风格配对为 SIZE、RISK、MOM。规则只给出“偏强 / 震荡 / 偏弱”和“Risk-On / 中性 / Risk-Off”，没有概率含义，也不是投资建议。

2026-05-25 附近的昨日情绪指数出现异常跳变。第一段只到 2026-05-22，第二段从 2026-05-26 开始；边界日和跨边界窗口直接拒绝，不用旧数据补齐。

## 指标

日收益优先按 `close / pre_close - 1` 计算；只有缺少价格时才使用 `pct_chg / 100`。趋势收益为：

```text
RetN = close_t / close_(t-N) - 1
Spread = 正向指数当日收益 - 负向指数当日收益
```

风格配对：

| 名称 | 正向 | 负向 |
|---|---|---|
| SIZE | `700050.TI` 微盘 | `700047.TI` 大盘股 |
| RISK | `700035.TI` 激进投资 | `700034.TI` 保守投资 |
| MOM | `700038.TI` 高动量 | `700039.TI` 低动量 |

广度来自 `data_pool/p00112` 的候选参数 `p0=A股`，映射 `f002=上涨、f003=平盘、f004=下跌`。候选范围尚未完成供应商对沪深京纯 A 语义的确认，所以结果标记为 `A_candidate_SH_SZ` 和“有限可用”。缺失值保留为 `None`，不转为零。

## 分类规则

方向判断要求主基准当日收益、Ret5、Ret20 同向：三者都为正时为“偏强”，三者都为负时为“偏弱”，其他情况为“震荡”。其中任一项缺失时输出“证据不足”。Ret60 只作为输出特征，窗口不足时为空。

风险模式统计三组 Spread：至少两组大于 0 为 `Risk-On`，至少两组小于 0 为 `Risk-Off`，否则为“中性”。上涨比例不低于 50%且净广度为正时增加“支持普涨”；指数上涨而净广度不为正时增加“权重托举风险”。高股息、昨日连板、昨日首板和昨日涨停表现只作辅助观察，不重复投票。

`vwap` 按用户确认记录为均价；首版不使用它决定方向。`CPS=1` 后复权、`CPS=2` 前复权的请求语义保留在 API 文档中。
