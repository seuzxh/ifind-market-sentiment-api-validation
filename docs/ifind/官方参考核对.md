# iFinD 官方参考核对

核对日期：2026-09-09。本文件只记录公开官方资料及待验证项，不代表业务接口实测通过。附件文件名为 v1.0，正文最新版本实际为 v1.7；附件和历史对话属于需求背景与既有证据，不能替代本轮响应。

## 1. 历史行情：必须区分端点

官方公开手册的 HTTP 示例使用 `POST /api/v1/cmd_history_quotation`，请求 JSON 中直接放 `codes`、`indicators`、`startdate`、`enddate`、`functionpara`，没有 `reqBody`。该章节给出的 CPS 映射为：`1` 不复权；`2` 前复权（分红再投）；`3` 后复权（分红再投），默认 `1`。[官方产品手册：历史行情](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/help-center/manual.html#历史行情-ths-hq)

附件示例使用 `/history_data`，并把 `CPS=1` 描述为后复权。本次公开官网检索没有找到该端点的正式参数页。因此：

- 不能直接把旧端点的枚举套在新端点上，也不能把附件映射视为已证实。
- 应分别记录 `history_data` 的顶层 JSON、`reqBody` JSON 与 `cmd_history_quotation` 对照结果。
- 指数在不同 CPS 下数值相同，不能证明参数无效，也不能证明其复权含义。需要在发生分红的个股区间做对照，并核对供应商生成命令。
- 公开资料未解决本轮 11 项字段的逐品种单位、VWAP 定义、指数成交量口径、换手率分母、修订机制。不可仅凭字段名或数值量级冻结单位。

## 2. 交易日历

官方日期查询手册列出：`dateType=0` 为交易日、`1` 为日历日；`period=D` 为日；`dateFormat=0/1/2` 分别输出 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`。SDK 市场标识采用 `SSE`、`SZSE` 等。[官方产品手册：日期查询](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/help-center/manual.html#日期查询-ths-datequery)

官方 HTTP 示例确有 `/get_trade_dates`，顶层参数包含 `marketcode=212001` 和 `functionpara`。页面的日期偏移示例还使用 `offset=-10` 与 `output=sequencedate`。[官方 HTTP 应用示例](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/example.html)

英文官方示例出现 `THS_Date_Query("212001", "mode:1,dateType:0,period:D,dateFormat:0", …)`。[官方英文应用示例](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/en/example.html)

尚未查得明确的 HTTP `marketcode` 数字字典及 `mode` 完整枚举。`212001` 与沪市的关系可以作为待核对线索，不能由 SDK 的 `SSE` 文档直接宣布 HTTP 覆盖沪深北。还需用真实返回核验 `mode=1`、端点包含性、非交易日和未来节假日。不能把“当前请求参数被接受”写成“所有枚举已确认”。

## 3. data_pool 报表

官方 HTTP 示例提供 `/data_pool`，参数为 `reportname`、`functionpara`、`outputpara`。示例使用 `p03425` 获取全部 A 股代码，并说明其他报表应通过超级命令工具查看。[官方 HTTP 应用示例](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/example.html)

本轮通过 `51ifind.com` 官方域名检索 `p00112`、`p03473` 未找到相应公开字段字典。这不意味着接口不存在，仅意味着没有公开官方参数证据。

| 对象 | 仍需取得的证据 |
|---|---|
| `p00112` | 纯 A 股枚举、沪深北范围、上涨/下跌/平盘/停牌定义、返回字段字典、截止日与发布时间 |
| `p03473` | 参数名与日期格式、历史成分是否真实生效、权重字段、生效日期和可见日期 |

附件保留的 AB 样例不能用于通过纯 A 股验收。成分在两个查询日相同也不能单独证明接口忽略历史日期：可能期间未调样，需要选择已知有成员变化的区间。

## 4. smart_stock_picking

官方示例确认 `POST /smart_stock_picking`，JSON 顶层字段为 `searchstring` 和 `searchtype`，示例范围为 `stock`。本次公开资料未找到 `index` 的完整枚举说明，需按用户提供的目录请求做实测。[官方 HTTP 应用示例](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/example.html)

目录返回代码和名称只能证明目录查询行为，不能证明指数编制规则、历史选样时点或数据发布时间。此前 `-1303 Device exceed limit` 属于历史请求记录，本文件未重放业务接口，不更新其状态。
