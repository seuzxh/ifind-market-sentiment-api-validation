# iFinD 接口验证与复用资料

版本：v0.1；验证日期：2026-09-09；状态：**已完成本轮可执行检查，REST 数据验收受凭证阻塞，尚未全部通过**。

本目录供后续项目复用接口定义、验证证据和复验用例，减少重复摸索。它不是已验收的生产 SDK。

| 文件 | 用途 |
|---|---|
| [API文档.md](API文档.md) | 按端点说明请求、字段、已知响应、异常与使用边界 |
| [验证报告.md](验证报告.md) | 本轮实测结果、证据索引与尚未通过的用例 |
| [待检查清单.md](待检查清单.md) | 最后由用户或供应商统一核对的事项 |
| [指数目录.csv](指数目录.csv) | 18条正式指数及3条对照的MCP单日交叉核对结果 |
| [官方参考核对.md](官方参考核对.md) | 官方来源、端点版本差异与资料缺口 |
| [requests.json](requests.json) / [复验.ps1](复验.ps1) | 凭证就绪后的固定日期REST复验用例与执行入口 |
| [evidence](evidence) | 本轮脱敏请求、响应、环境检查和校验记录 |

先看验证报告，再按待检查清单补齐阻塞项。API文档中的“历史记录”“官方资料”“本轮HTTP实测”“本轮MCP实测”是不同证据等级，不能互相替代。

本轮沿用附件正文v1.7的范围：18条正式指数、纯A股广度、交易日历；成分接口记录契约和后续用例。行业、概念、题材、分类股池归因、分钟行情和T+1模型暂缓。

历史任务中仅以内容引用显示的其他产物，本次未取得其文件实体；读取到的对话正文和最初需求节选仅作为历史背景。当前正式输入是用户上传的验证方案。原附件保持不变。
