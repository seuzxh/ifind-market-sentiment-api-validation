# 实时行情与分钟K接口

## `real_time_quotation`

```text
POST https://quantapi.51ifind.com/api/v1/real_time_quotation
codes=883957.TI
indicators=riseCount,fallCount,upLimitCount,downLimitCount,suspensionCount,tradeDate,tradeTime,preClose,open,high,low,latest,latestAmount,latestVolume,volume,amount,changeRatio,change,swing
```

用于盘中上涨/下跌家数、涨停/跌停家数、停牌家数及指数实时行情。字段定义、市场范围、更新时间和是否为累计量需以成功响应核对。

## `high_frequency`

```text
POST https://quantapi.51ifind.com/api/v1/high_frequency
codes=883957.TI
indicators=open,high,low,close,avgPrice,volume,amount,change,changeRatio,changeRatio_accumulated
functionpara={"Fill":"Original"}
starttime=2026-09-07 09:15:00
endtime=2026-09-09 15:15:00
```

复权参数按用户确认记录：不复权为`Fill=Original`；前复权增加`CPS=forward`；后复权增加`CPS=backward`。`changeRatio_accumulated`仅支持当日，不能跨交易日解释为连续累计收益。分钟数据必须按交易日分段，不能跨2026-05-25异常边界。

本轮实测：`real_time_quotation`在2026-09-09盘中返回HTTP200/`errorcode=0`，取得上涨2066、下跌3304、涨停43、跌停6等快照字段；`suspensionCount`为null，需按缺失处理。`high_frequency`查询2026-09-08返回HTTP200但`errorcode=-4224 date index is invalid`；改查当前交易日2026-09-09成功返回1分钟序列，说明该接口当前可能只支持当日高频数据。请求成功仍需核对时间粒度、午休、缺口、量额单位和复权一致性。原始脱敏证据保存在`evidence/realtime-*`目录。
